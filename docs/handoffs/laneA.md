**What changed**

- How it works: the loop, `ArchitectureDiagram` (built parts solid; PostgreSQL+pgvector, Embeddings API and LLM adapter dashed and labelled "planned"), 4 trust cards, and links to Evaluation and Help.
- Nav: 9 plain-word groups (Start, Watch, Problems, Investigate, Remember, Act, Review, Lab, Help). Each item has an icon and a hint (tooltip, plus shown under the label in `--indigo-200`). Simple mode merges Review and Lab into "For reviewers", collapsed by default and auto-opened when it holds the active page. Shortcuts: `g g` Home, `g b` briefing, `g y` how-it-works, `g v` problem list, `g q` help; the others are as in the brief. The palette lists all 20 items and searches hints. `activeItem` handles `/app`, `/app/briefing`, nested routes and `/app/cases/*`.
- TopBar: the breadcrumb was being squeezed to a few characters. The controls no longer shrink; LLM chip and Ctrl K text are hidden below 1600px; the sim clock is compact (full date in the tooltip). Nothing was removed.
