# web-shell-1 — UI kit + shell (for page builders)
Run: `cd apps/web && npm run dev` → http://localhost:3000 (engine via rewrite `/api/engine/*` → `ENGINE_URL` default `http://127.0.0.1:8000`). Checks: `npx tsc --noEmit`, `npm run build`, `node scripts/lint-hex.mjs` (repo root). Pages live in `src/app/app/<route>/page.tsx`; mark them `"use client"` when using hooks. Shell, persona and top bar already wrap every `/app/*` page; start each page with `<PageHeader>`.

**API** `@/lib/api/client`: `apiGet<T>(path)`, `apiPost<T>(path, body?)`, `apiPatch<T>(path, body?)` (throw `ApiError{status, message, body}`; `detail` from FastAPI becomes the message) · `useApi<T>(path: string | null) → {data: T|null, error: Error|null, loading, reload()}` (null = skip; refetches on path change) · `qs(path, {k: v})` builds query strings and skips empty values. Paths are engine paths, e.g. `useApi<RisksResponse>(qs("/risks", {persona}))`.
**Types** `@/lib/api/types`: `PersonaKey, Severity, Kind, Provenance, Health, Briefing, Priority, HeldBack, Note, PortfolioHealth, IncidentSummary, RisksResponse, IncidentDetail, Evidence, Series, Investigation, AgentStep, MemoryMatch, Plan, PlanStep, Draft, Approval, DecisionRequest, DecisionResponse, Task, Outcome, MemoryItem, MemorySearchResponse, AskResponse, AccountRow, AccountDetail, NextBestAction, AuditRow, AuditResponse, AuditVerify, TimeToActionResponse, EvalResponse, EvalRun, SourcesResponse, Feed, CatalogSignal, LabAdvanceResponse, NotebookEntry, ListResponse<T>`.
**Persona** `@/lib/persona`: `usePersona() → {persona: PersonaKey, label, setPersona}` · `PERSONAS` · `personaLabel(key)`.
**Format** `@/lib/format`: `fmtINR(v, {compact=true, digits=1})` gives "₹4.2 L" / "₹1.3 Cr" / "₹12.5 K" · `fmtPct(fraction, {digits=0, signed=true})` gives "−31%" · `fmtNum(v, digits=0)` · `fmtDate(iso, withTime=false)` gives "9 Oct 2026 09:00" (no TZ shift) · `fmtAgo(iso, now=new Date())` (pass `sim_now` for sim data) · `fmtDuration(seconds)` · `humanize("snake_case")`.

**UI kit**: everything below imports from `@/components/ui`.
- `<Metric label value meaning implication provenance delta? deltaTone?="up"|"down"|"neutral" tone?="default"|"critical"|"healthy"|"elevated">`. `meaning`, `implication` and `provenance` are REQUIRED. `delta` is a preformatted string (use `fmtPct`).
- `<ChartFrame title meaning implication provenance height?=240 actions?>{<EChart option={...}/>}</ChartFrame>`. The three captions are REQUIRED.
- `<EChart option height?="100%" ariaLabel? onEvents?>`: client-only, token theme, no legend, 200ms animation (0 under reduced motion). Write colours as `"var(--chart-2)"` or `chartColor(1..5)`; any `"var(--x)"` string in the option is resolved at runtime. Add a baseline with `markLine: baselineMarkLine(value, "Baseline")` (dashed grey). Use at most 3 series and label them directly.
- `<DataTable columns data provenance caption onRowClick? emptyText? initialSort? maxHeight?>` (TanStack v8 `ColumnDef<T>`, also re-exported as `ColumnDef`). `provenance` and `caption` are REQUIRED. Column `meta: {mono?, numeric?, help?}`; columns with id `id`/`ref`/`*_id` render in mono automatically. Columns sort, the header is sticky, rows are 36px, and Enter on a row works like a click.
- `<SeverityPill severity>` · `<StatusPill status tone?="neutral"|"info"|"ok"|"warn"|"bad" label?>` · `<EvidenceChip id label? onClick?(id)>`.
- `<EmptyState title body? action?>` · `<ErrorState error onRetry? title?>` · `<Loading rows?=5 label?>` (skeleton). Every async view needs all three, e.g. `if (loading) <Loading/>; if (error) <ErrorState error={error} onRetry={reload}/>`.
- `<PageHeader question title>{actions}</PageHeader>` · `<Card title? actions? provenance? flush?>` · `<Tabs tabs={[{id,label,content}]} value? onChange? defaultValue?>` · `<Drawer open onClose title footer?>`.
- `<Button variant?="primary"|"secondary"|"ghost"|"danger" size?="md"|"sm" icon?>` · `buttonClass(variant, size)` styles a `<Link>` as a button. Import it from `@/components/ui/Button` in server components.
- `<Caption meaning? implication?>` · `<ProvenanceBadge provenance>`.
- CSS helpers (globals.css): `.grid .grid--2/3/4`, `.stack`, `.row`, `.caption`, `.mono`, `.num`, `.muted`, `.card`, `.pill pill--*`, `.chip`, `.kbd`.

**Shell** (`@/components/shell`): `AppShell, Sidebar, TopBar, SyntheticBadge, ModeChip, SimClock, PersonaSwitcher, CommandPalette, NAV, NAV_ITEMS, activeItem`. Keyboard: `g` then a letter (b h s r o a i m p w u t e l x n), `Ctrl+K` opens the palette, and the sidebar collapses (state persisted).
**Rules**: no hex or rgb literals outside `src/styles/tokens.css` (enforced by lint-hex). Use `var(--…)` tokens only. Never use `--crimson-600` for text.
